## Decisions to confirm

1. Python 3 standard library replaces PowerShell (FR-001). Alternatives
   considered: keeping `pwsh` 7 (cross-platform, but an extra install on
   macOS/Linux), Node (an extra install where projects are not JS), shell
   scripts (Windows gap).
2. Landing detection uses `git merge-tree --write-tree`, so squash-merged
   worktrees are cleaned too (FR-013).
3. Cleanup runs from `post-merge`/`post-rewrite` hooks after pulling the
   target; no hook can fire on a remote PR merge (FR-015).
4. The scheduler commits directly to the package branch in its own worktree
   and no longer cherry-picks into the primary checkout (FR-032).
5. Quota triggers fallback to the next agent instead of stopping (FR-035).
6. At most two review rounds per checkpoint (FR-022).
7. Closeout, migrate, mirror diff and legacy TODO mode are removed;
   `v1-powershell` tag preserves them (FR-040).
